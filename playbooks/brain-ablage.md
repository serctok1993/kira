# Brain-Vault-Ablage

> Regel: **Wichtiges -> Obsidian. Existenzielles/Kritisches -> Memory/SOUL.**
> Der Vault ist sein zweites Gehirn — Ablage auf einen Haufen ist keine Pflege.

## Ordner-Landkarte (Vault-Wurzel)

| Inhalt | Ziel-Ordner |
|---|---|
| Erkenntnisse, Gelerntes, Aha-Momente | `GELERNT/` (wichtige zusaetzlich als Zeile in GELERNT/INDEX.md) |
| Ideen, Einfaelle, Spinnereien | `IDEEN/` |
| Vertrieb, Leads, Akquise, Geschaeftliches | `Business/` (Akquise-Entwuerfe: `Business/Akquise/Entwuerfe/`) |
| Produkt-/Technik-Notizen des eigenen Projekts | Projekt-Ordner im Vault |
| Personen-Geschichten, Privates, Gesundheit | `Leben/` |
| Recherche-Dossiers | `dossiers/` |
| Tagesjournal-Destillate | `tagesjournal/` |
| Arbeitsanweisungen/Prozesse von {{USER_NAME}} | `SYSTEM/` (nur lesen — schreiben nur auf Auftrag!) |
| Unklar/Sonstiges | `notizen/` |

## Regeln

1. **NIE neue Top-Level-Ordner erfinden.** Im Zweifel -> `notizen/`.
2. Personen-FAKTEN (Geburtstag, Wohnort, Vorlieben) -> IMMER `person_fakt`
   (fuettert das Termin-Radar). Laengere Personen-KONTEXTE/Geschichten -> `Leben/`.
3. Einzelfakten ueber {{USER_NAME}}/Betrieb -> `remember_fact`, NICHT als Mini-Notiz in den Vault.
4. Existenzielle Verhaltensregeln ("mache nie X", "immer erst Y") -> gehoeren in
   SOUL/ARBEITSWEISE — {{USER_NAME}} Bescheid geben statt selbst schreiben.
5. Bestehende Notizen ERGAENZEN (Update-Abschnitt) statt Parallel-Dateien anzulegen —
   vor dem Anlegen kurz `datei_finden` im Vault.
